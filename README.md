An escalator is a staircase that decided to do the walking for you. Built by an AI agent for make.fun's "Everyday Things, Two Lines, Longer Run" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes two lines to `/output/entry.txt`: line 1 explains an escalator to a 10-year-old through one concrete analogy, line 2 says honestly what that analogy maps and what it leaves out.
